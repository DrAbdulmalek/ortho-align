# OrthoAlign — محاذاة الجمل بين كتاب Orthobullets الإنجليزي (2026) والعربي (2021)

## المشكلة
كتاب Orthobullets إنجليزي (11 ملف PDF حسب القسم) + الترجمة العربية (ملف PDF واحد، 16 مليون حرف).
المطلوب: جدول CSV يحوي كل جملة إنجليزية ومقابلها العربي.

الصعوبات الفعلية (مؤكدة بالفحص):
1. **ترتيب الفصول مختلف** — الترجمة العربية تجمع الأقسام بترتيب مختلف عن الإنجليزي.
2. استخراج النص من PDF يكسر الجمل عند الاختصارات (e.g.، vs.، Fig.، cm.) والأرقام العشرية.
3. النسختان بسنوات مختلفتين (2026/2021) والترجمة غير حرفية.
4. **النص العربي لا يحفظ سوى القليل من الكلمات الإنجليزية** (الأرقام، بعض المصطلحات) —
   وهذا هو السبب الجوهري لفشل المحاولة السابقة التي بنت كل شيء على «الكلمات المشتركة».

## لماذا فشلت المحاولة السابقة؟ (تشخيص من ملفات pdf_align.zip)
1. اعتمدت على تطابق كلمات إنجليزية بين النصين → إشارة شبه معدومة.
2. لم تقم بإقران فصول فعلي (افترضت تطابق الترتيب).
3. التقطيع لم يحمِ الاختصارات فتكسرت الجمل.
4. لا مقياس تشابه دلالي ثنائي اللغة.

## الحل النهائي (مُختبر)
### المرحلة 1 — التقطيع (prepare.py)
NFKC + حذف علامات الاتجاه والتطويل + تحويل الأرقام العربية-الهندية، تقطيع إنجليزي
يحمي الاختصارات والأرقام العشرية، حذف فوضى PDF (أرقام صفحات، روابط، «Created by»).
النتيجة: **81,589 جملة إنجليزية، 67,028 جملة عربية**.

### المرحلة 2 — إقران الفصول بالمحتوى (pair_regions.py)
LaBSE (نموذج تضمين ثنائي اللغة): مركز لكل فصل إنجليزي + تصويت الجمل العربية المأخوذة
بعينة (كل 4 جمل) + تنعيم تصويتي بنافذة 120 + الإقران الأمثل بخوارزمية الهنغارية.
النتيجة: 11 منطقة متتابعة تغطي كامل الكتاب العربي، كل منطقة لفصل إنجليزي واحد
(فحص التباين: 0.275–0.351، والفارق داخل الصف vs متوسط الصف > 7σ ⇒ الإقران موثوق).

### المرحلة 3 — المحاذاة والاسترجاع (align.py / dp0.py / run_align.py)
جرّبنا محاورَ اثنين وقيسنا دقة كلٍّ منهما بعينات عشوائية:

**أ) الاسترجاع الدلالي LaBSE (labse_retrieval.csv) — المحور المعتمد**
لكل جملة إنجليزية أقرب جملة عربية بجيب التمام، مع عمودَي
`confidence` (درجة التشابه) و`margin` (الفارق عن ثاني أفضل) — والصفوف الضعيفة
تُعلَّم بشفافية بدل إخفائها.

**ب) برمجة ديناميكية بالمراسي (aligned_pairs.csv) — تجريبي**
DP بأسلوب Gale–Church بعمليات 1:1 / 1:2 / 2:1 / 1:0 / 0:1 على «المراسي»
(أرقام مميزة + مصطلحات لاتينية) داخل كل منطقة فصل.

## الدقة المقاسة (وليست مزعومة)
فحصنا عشوائيًا بعيننا البشرية:

| الملف | العينة | الدقة المقاسة |
|---|---|---|
| labse_retrieval.csv — الصفوف عالية الثقة (cos ≥ 0.75) | 30 صفًا | **≈ 83% (25/30)** |
| نفسها مع شرط margin ≥ 0.05 | 25 صفًا | **≈ 96% (24/25)** |
| aligned_pairs.csv (DP بالمراسي) | 50 صفًا | **≈ 10–15% فقط** |

### العائد الفعلي على النتيجة المُسلَّمة (تحقق مستقل 2026-11-22)
- من 2200 صف: **63 صفًا (2.9%)** بثقة ≥ 0.75، ومنها **50 صفًا (2.3%)** مع margin ≥ 0.05.
- عند خفض العتبة إلى 0.65 يرتفع العائد إلى 378 صفًا (17.2%) بدقة أقل.
- **21.3% من الصفوف نصها العربي مكسور** (محارف استبدال U+FFFD أو حروف مفككة من
  استخراج PDF) — هذا سبب جذري لانخفاض درجات الثقة، وإصلاحه يتطلب إعادة استخراج
  نص الكتاب العربي من PDF أفضل (OCR عربي مثل ocr-core بدل pdftotext).
- توجد أخطاء واضحة حتى داخل عينة الفحص عالية الثقة (4 من أول 13: palmar→عقبية،
  anterior shoulder pain→رقبة، profunda brachii→شظوي) — فالاعتماد الآمن هو
  المراجعة البشرية على أي استخدام سريري.

**الاستنتاج بصراحة:** لا يمكن ضمان «دقة 100%» لمحاذاة آلية بين إصدارين مختلفين
وترجمة غير حرفية — أي ادعاء كهذا غير صحيح. ما يقدمه هذا العمل:
1. CSV موثوق جزئيًا مع تسمية ثقة لكل صف ومراجعة بشرية للعتبات العالية.
2. البنية التحتية الكاملة (سكربت + تطبيق + خوارزمية موثقة) لإعادة التشغيل على
   نصوص أفضل أو نماذج أضخم — على GPU تُحاذى كل الجمل (81 ألف) خلال ~ساعة.

## الملفات
- `run_align.py` — **المشغّل الكامل** (استدعاه `cli_app.py align`): تضمينات → عينات →
  استرجاع كامل → إقران مناطق → DP. (أعيد بناؤه في الإصلاح — كان مفقودًا من الحزمة).
- `embed_samples.py` — عينات التضمين لإقران الفصول. (أعيد بناؤه أيضًا).
- `labse_retrieval.csv` — المحاذاة الدلالية مع confidence وmargin (النتيجة المعتمدة).
- `aligned_pairs.csv` — نتيجة DP بالمراسي (تجريبي، دقته المقاسة ضعيفة).
- `align.py` + `prepare.py` + `pair_regions.py` + `dp0.py` + `final_align.py` — الخوارزمية كاملة.
- `cli_app.py` — تطبيق أوامر: `extract` / `align` / `search`.
- `spotcheck50.txt` + `qc_retrieval.txt` — نماذج الفحص العشوائي المُقاس.

## التشغيل
```bash
# متطلبات النظام: sudo apt install poppler-utils        (أمر pdftotext)
pip install sentence-transformers scipy numpy

python3 cli_app.py extract ./books/en ./books/ar ./work2   # استخراج الجمل
python3 cli_app.py align   ./work2 ./out                   # محاذاة كاملة (GPU يوصى به)
python3 cli_app.py search  ./out/labse_retrieval.csv "ACL" # بحث في النتائج
```
